# The paper

`induction-tab.tex` is the source and `induction-tab.pdf` is the build. The text types no results by hand. It reads them from `numbers.tex`, which `numbers.py` writes from `results/` and the other files it names beside each value.

## How to rebuild

You need Python 3 and [tectonic](https://tectonic-typesetting.github.io/). Both scripts use only the standard library. The first tectonic build downloads the LaTeX packages.

From the repository root:

```sh
python3 paper/numbers.py --write
python3 paper/figures.py
cd paper && tectonic induction-tab.tex
```

Nothing here trains a model or uses the GPU.

## How to check it

```sh
python3 paper/numbers.py
```

The bare run recomputes every value and exits with an error if:

- a value disagrees with its file or with `numbers.tex`
- a stated summary disagrees with the raw run file behind it
- the text uses an undefined number macro, or types a decimal, a count of two or more digits, or a number in scientific notation
- the text, this file or `SUBMIT.md` contains a long dash, a local path or a word the paper's rules exclude

## Files

- `induction-tab.tex`: the text, tables and bibliography.
- `numbers.py`: recomputes every value, writes `numbers.tex` and runs the checks.
- `numbers.tex`: generated, with one macro per value.
- `figures.py`: draws the figures from the result files as TikZ.
- `fig-survival.tex`, `fig-depth.tex`, `fig-gap.tex`: generated by `figures.py`.
- `SUBMIT.md`: what an arXiv or Zenodo submission needs.
